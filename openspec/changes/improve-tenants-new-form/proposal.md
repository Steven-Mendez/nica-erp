## Why

The current `/tenants/new` wizard ships five concrete UX defects
that the operator surfaced during hands-on use:

1. The default Zod errors leak English copy into a
   Spanish-only product — e.g., submitting an empty municipio
   renders `String must contain at least 1 character(s)`,
   which is the Zod default. The schema in
   `apps/web/src/features/tenants/schemas/index.ts` declares
   `z.string().min(1)` etc. without an explicit Spanish
   `message`. This violates [[feedback_spanish_ui]].
2. **Régimen** is a bare `<select>` HTML element — visually
   inconsistent with the rest of the shadcn-styled wizard, no
   keyboard nav highlight, no theme support.
3. **Municipio** is a free-text `<Input>` even though the
   backend enforces a 17-municipality catalog (`KNOWN_MUNICIPALITIES`
   in `apps/api/src/contexts/tenants/domain/municipality.py`).
   The user can type anything and only discover the
   restriction at the POST round-trip.
4. **Es retenedor** is a bare `<input type="checkbox">` with
   no affordance — a non-accountant operator has no way to
   know what "retenedor" means without leaving the wizard.
5. **No tooltips** explaining fiscal-specific terms means
   first-time users abandon the wizard at the régimen / DGI /
   retenedor decisions.

Sprint 3.6 (`welcome-onboarding-rename-members`) plans to
rewrite the entire wizard at `/organizations/new`, but that
rename has not landed yet and the operator is using
`/tenants/new` today. The fixes below land on the existing
route and are scoped narrowly enough to be carried forward
verbatim when sprint 3.6 rewrites the route file.

## What Changes

- Add Spanish `{ message: "..." }` to every `z.string().min(…)`,
  `z.string().max(…)`, `z.string().email(…)`, and
  `z.string().regex(…)` in
  `apps/web/src/features/tenants/schemas/index.ts`. Covers
  `createTenantSchema`, `updateTenantSchema`,
  `inviteMemberSchema`, `updateMemberRoleSchema`.
- Install shadcn `select` and replace the bare
  `<select id="regime">` in the Régimen step with `<Select>` +
  `<SelectTrigger>` + `<SelectContent>` + `<SelectItem>` for
  the two régimen options (General / Simplificado).
- Replace the bare `<Input id="municipality">` in the same step
  with a `<Select>` over the canonical 17-municipality catalog
  (mirrors the backend `KNOWN_MUNICIPALITIES` set). Maintain
  the catalog as a frontend constant
  `apps/web/src/features/tenants/municipalities.ts` so the
  wizard, picker, and any future filter share one source.
- Install shadcn `checkbox` and `tooltip`. Replace the bare
  `<input type="checkbox">` for `is_withholder` with
  `<Checkbox>` + `<Label>`, and wrap an info-circle icon next
  to the label inside a `<Tooltip>` whose content explains
  "Un retenedor IR es una empresa designada por la DGI para
  retener impuestos a sus proveedores en cada pago."
- Add shorter tooltips next to Régimen ("General: factura IVA
  estándar. Simplificado: cuota fija mensual.") and DGI número
  ("Número de autorización de impresión emitido por la DGI
  para los rangos de comprobante fiscal.").
- All visible strings stay in Spanish per [[feedback_spanish_ui]].

## Impact

- Affected code:
  - `apps/web/src/features/tenants/schemas/index.ts` — Spanish
    messages on every constraint.
  - `apps/web/src/features/tenants/municipalities.ts` — new
    file: `MUNICIPALITIES` constant (17 entries, mirrors the
    backend catalog).
  - `apps/web/src/routes/tenants/new.tsx` — swap `<select>` →
    `<Select>` for régimen, `<Input>` → `<Select>` for
    municipio, `<input type="checkbox">` → `<Checkbox>` for
    `is_withholder`, add `<Tooltip>` icons next to Régimen,
    Municipio, DGI número, and Es retenedor labels.
  - `apps/web/src/components/ui/select.tsx`,
    `apps/web/src/components/ui/checkbox.tsx`,
    `apps/web/src/components/ui/tooltip.tsx` — new files,
    generated by `pnpm dlx shadcn@latest add select checkbox
    tooltip`.
- Affected dependencies:
  - `apps/web/package.json` gains `@radix-ui/react-select`,
    `@radix-ui/react-checkbox`, `@radix-ui/react-tooltip` (peer
    deps of the shadcn primitives).
- Affected tests:
  - `apps/web/tests/unit/routes/tenants-new.test.tsx` — new
    file (no prior test for this route): asserts Spanish
    error on empty name, Régimen Select renders both options,
    Municipio Select renders 17 options, Tooltip on "Es
    retenedor" surfaces the explanation copy.
- Affected docs:
  - `docs/sprints/03-tenants-and-rls.md` — append a "Sprint
    follow-up — `/tenants/new` form ergonomics (sprint 3.8,
    2026-05-27)" section after the existing 3.7 follow-up.
  - `openspec/changes/welcome-onboarding-rename-members/tasks.md`
    — add a `Carry over /tenants/new improvements` task so the
    sprint 3.6 rewrite preserves the Select/Checkbox/Tooltip
    primitives and Spanish error messages.
- Not affected:
  - DGI date inputs (`valid_from`, `valid_to`) — staying as
    `<Input type="date">` until a `date-picker` follow-up
    (separate change). Their Zod regex error gets a Spanish
    message, but the input affordance does not change here.
  - Any other route, the backend, or the
    `useCreateTenantMutation` / `useSwitchTenantMutation` hooks.
- No ADR: this is tactical UI polish inside the shadcn/ui
  envelope of [ADR-0009](../../../docs/adr/0009-frontend-stack.md);
  picking specific shadcn primitives is not architectural.
